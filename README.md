# AutoMarket - E-commerce de autos y repuestos

Proyecto educativo realizado con PHP, HTML, CSS y MariaDB/MySQL.

## Requisitos
- PHP 8 o superior
- MariaDB/MySQL
- Apache (XAMPP recomendado)
- Git

## Instalación
1. Copiar la carpeta `automarket` dentro de `htdocs`.
2. Crear la base de datos ejecutando `database/automarket.sql` desde phpMyAdmin.
3. Revisar `config/database.php` y colocar usuario/contraseña de MariaDB.
4. Abrir:
   `http://localhost/automarket/`
